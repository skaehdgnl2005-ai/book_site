# 동화책 미리보기 뷰어 (펼침면 플립) — 설계 (F077)

날짜: 2026-07-23 · 상태: 사용자 승인(대화) 후 구현 착수 · 트랙: product

## 목적

엔트리 구매 여정에서 구매 확신을 주는 **책 넘김(플립) 미리보기**를 제공한다. 템플릿(=상품)마다
펼침면(스프레드) 몇 장을 넘겨 보고, 마지막 장의 CTA로 주문 흐름에 복귀한다. 실제 내지 이미지는
백스테이지 파이프라인 대기 중이므로 **타이포그래픽 플레이스홀더 스프레드로 선행**한다(갤러리 F025와
같은 정직한 패턴 — 메커니즘·E2E를 지금 완성하고 에셋은 나중에 갈아끼움).

## 핵심 결정 (대화에서 확정)

1. **넘김 단위 = 펼침면(spread) 1장 = 10:7 한 덩어리.** 그림책의 실제 구성 단위. 가로 풀블리드
   장면도, 좌 글/우 세로 그림 구성도 전부 이 단위 안에서 표현된다 → 모바일에서 "반쪽 장면" 문제가
   구조적으로 사라진다.
2. **모바일(세로)**: 스프레드를 통째로 fit-width로 보여준다(panel 매트 위 레터박스). 낱장(leaf)
   플립 애니메이션 유지. 회전하면 크게 보인다는 **힌트 문구**(microLabel) 제공. **줌(핀치/더블탭)은
   1차 범위에서 제외** — 후속 피처.
3. **데스크톱(≥768px)**: 같은 10:7 스프레드를 좌/우 반으로 갈라 두 페이지로 렌더 → 접힘선이 실제
   책처럼 책등(가운데)에 온다.
4. **플립 감성 필수** → `page-flip`(StPageFlip) 바닐라 패키지를 우리 클라이언트 컴포넌트로 직접
   래핑(React 19 peer 이슈가 있는 react-pageflip 래퍼는 쓰지 않음). 뷰어를 열 때만 dynamic
   import(카테고리/주문 페이지 번들 무영향). `maxShadowOpacity ≤ 0.1`(DESIGN.md 그림자 금지 정신).
5. **`prefers-reduced-motion`**: PageFlip을 아예 초기화하지 않고 같은 마크업을 크로스페이드
   전환으로 렌더(DESIGN.md 모션 하드 가드). 이 폴백은 라이브러리 로드 실패 시의 폴백도 겸한다.
6. **진입점**: 주문 위저드 퍼널 헤더 — `contextBlurb`/`included` 바로 아래 텍스트 링크
   **"이 책 미리 읽기 →"** (DESIGN.md 텍스트 링크 문법, hover 화살표 5px 이동). 어느 스텝에서든 보임.

## 구성요소

- `src/app/_components/preview/previewSpreads.ts` — 순수 데이터: `previewSpreadsFor(template)` →
  템플릿 키별 이야기 도입부 문장 스프레드 4장 + 마지막 **CTA 장**("이야기의 끝은 아이의 이름으로
  완성됩니다" + "이 책 만들기"). 미등록 키는 제네릭 폴백(미래 DB 템플릿 안전).
- `src/app/_components/preview/BookPreviewViewer.tsx` (`"use client"`) — 풀스크린 오버레이
  `role="dialog"` + `aria-modal`. 상단 바: 책 제목만 명조(`「탄생」`) + 닫기. 중앙: panel 매트 위
  플립 스테이지. 하단: 헤어라인 위 `1 / 5` 인디케이터(grotesk) + 이전/다음 버튼(스와이프/드래그 병행,
  키보드 ←/→, Esc 닫기). 모바일 세로에서만 회전 힌트 한 줄.
- `OrderWizard.tsx` — 퍼널 헤더에 진입 링크 + 뷰어 open 상태.
- 마지막 CTA 장의 "이 책 만들기"는 오버레이를 닫고 위저드로 복귀(이미 해당 템플릿 주문 화면 위에 떠
  있으므로 네비게이션 없음). 오버레이는 자체 화면이므로 네이비 필 1개 규칙과 충돌하지 않는다.

## 브레이크포인트 전환

컨테이너 <768px → 낱장 모드(페이지 = 스프레드 전체, 10:7), ≥768px → 두쪽 모드(페이지 = 스프레드
절반, 5:7). 모드가 바뀌면 PageFlip 인스턴스를 destroy 후 재생성(페이지 DOM이 다르므로). 플레이스홀더
스프레드는 DOM 콘텐츠이므로 "절반"은 스프레드 레이아웃을 half 단위로 재렌더해 구현(이미지 에셋 도입
시 같은 자리에서 `background-position` 슬라이싱으로 대체).

## 에셋 계약 (후속 — 실제 이미지 도입 시)

`public/previews/<templateKey>/spread-01.webp …` · 10:7 · 장당 ≤300KB · 워터마크는 파이프라인에서
이미지에 굽는다(웹 CSS 워터마크는 소프트 조치일 뿐임을 인정). 파일이 존재하면 플레이스홀더 대신
이미지 스프레드를 렌더하도록 `previewSpreads.ts`가 분기하는 것은 에셋 도착 시의 작은 후속 작업.
